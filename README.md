# Basics of Mathematics
## Student Workbook Winter 2026

### Instructions for students

1. **Fork this repository** to your own GitHub account.

2. The assignments are located in the `exercises` directory.

3. Empty Markdown files prepared for your answers are located in the `solutions` directory.

4. Each exercise corresponds to one Markdown file in `solutions`.

5. Complete the appropriate Markdown file with your solution.

6. Commit and push your completed solution to **your forked repository**.

7. Enable **Issues** in your fork:
   - open your forked repository,
   - go to **Settings**,
   - in **General → Features**, enable **Issues**.

Issues will be used by the instructor to communicate comments about your work, including information about what still needs to be completed, corrected, or improved.

Issues are **not used for communicating grades**. Grades and other formal course communication are provided during classes or by email.

Do not create Pull Requests to the original repository unless explicitly requested by the instructor.
